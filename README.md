## 🌟 Overview

**Elite Regewelt** is a state-of-the-art, high-performance web platform dedicated to mastering the
German language from levels **A1 to B2**, with a specialized focus on rigorous preparation for
official **Goethe-Zertifikat** and **ÖSD** examinations.

Engineered with **Astro 7**, **Tailwind CSS v4**, and **Vue 3 Islands**, the application combines
lightning-fast static generation (Zero-JS baseline) with rich interactive components, fluid
micro-interactions, neural speech pronunciation, and comprehensive pedagogical structures.

---

## 🎯 Key Learning Pillars

### 1. Thematischer Wortschatz (Vocabulary Hub)

- **12 Comprehensive Everyday & Professional Categories:**
  - _Menschen, Zu Hause, Essen & Trinken, Unterwegs, In der Stadt, Bildung & Beruf, Kommunikation,
    Freizeit, Körper & Gesundheit, Notfälle, Erde & Natur, Zahlen & Maße_.
- **Over 100 Subtopics & Rich Data Records:** Complete with German definitions, Arabic translations,
  phonetic transcriptions, and authentic sample sentences.
- **Contextual Narrative Stories:** Every topic contains immersion reading passages (_TopicStory_)
  demonstrating words in natural context.
- **Pedagogical Table Views:** Sortable, searchable vocabulary matrices with native audio triggers
  and plural formation highlights.

### 2. Deutsche Grammatik (Grammar Engine)

- **6 Core Structural Modules:**
  - **Verben:** Tempora (Präsens, Präteritum, Perfekt, Plusquamperfekt, Futur I & II), reflexive &
    trennbare Verben, Verben mit Präpositionen, Konjunktiv I & II, Passiv, Partizipien, and
    Funktionsverbgefüge.
  - **Nomen & Artikel:** Genus rules, n-Deklination, 4 Kasus (Nominativ, Akkusativ, Dativ, Genitiv),
    Adjektivdeklination, Komparation, and Nominalisierung.
  - **Präpositionen:** Lokale, temporale, modale, kausale, Wechselpräpositionen, and fixed Genitiv
    prepositions.
  - **Satzbau:** Hauptsätze, Nebensätze (_weil, dass, obwohl, wenn, etc._), Relativsätze, Infinitiv
    mit _zu_, and Satzverbindungen.
  - **Adverbien & Partikeln:** Temporale, lokale, kausale Adverbien, Modalpartikeln (_doch, mal,
    ja_), and Negationsregeln (_nicht vs. kein_).
- **Interactive Visual Cards & Rule Blocks:** Clear grammatical tables, color-coded case markers,
  and step-by-step syntactic breakdowns.

### 3. Prüfungsvorbereitung B1 & B2 (Exam Mastery)

- **Modular Breakdown for Goethe-Zertifikat & ÖSD B1 / B2:**
  - **Lesen (Reading):** 65 minutes (5 Teile in B1) — format strategies, distractors, timing
    management.
  - **Hören (Listening):** 40 minutes (4 Teile in B1) — audio cues, note-taking techniques.
  - **Schreiben (Writing):** 60 minutes (3 Aufgaben in B1) — personal letters, formal responses,
    discussion opinions.
  - **Sprechen (Speaking):** 15 minutes — joint planning, two-part presentation, conversational
    defense.
- **Pass Criteria Clarity:** Explicit 60% (60 points) pass mark guidelines per independent module.
- **Redemittel Phrase Banks:** Over 100 categorised, battle-tested connectors, transition formulas,
  and formal opening/closing phrases.

### 4. Prüfungsthemen (64 Speaking & Writing Themes)

- **Structured 5-Step Presentation Architecture:**
  1. _Foliengestaltung & Einleitung_ (Introduction & Structure)
  2. _Persönliche Erfahrung_ (Personal Experience & Context)
  3. _Situation im Heimatland_ (Situation in Home Country)
  4. _Vor- & Nachteile mit Bewertung_ (Balanced Pros & Cons)
  5. _Abschluss & Eigene Meinung_ (Conclusion & Future Outlook)
- **Curated Topics:** From Artificial Intelligence, Remote Work, and Organic Food to Climate Action,
  Higher Education, and Public Transit.

### 5. Interaktive Quizze (Vue 3 Islands)

- **38+ Real-World Exam Simulation Tests:** Authentic reading comprehension scenarios with instant
  scoring and explanation modals.
- **Context Cards & Ad Detail Modals:** Realistic classified ads (_Anzeigenzuordnung_) with
  high-fidelity visual cards and responsive interactive overlays.
- **Teil 1 to Teil 5 Workflow:** Step-by-step progress tracking, timer simulations, and post-quiz
  analytics.

### 6. Edge Neural Text-to-Speech (TTS Engine)

- **High-Fidelity Audio Pronunciation:** Integrated serverless API route (`/api/tts`) powered by
  `msedge-tts` with native German neural voices.
- **Multi-Tiered Fallback & Resilience:** Automatic fallback to Google TTS chunking, in-memory LRU
  caching (up to 500 audio buffers), and circuit-breaker protection.

## 🏛️ Technical Architecture

The codebase adheres strictly to **Feature-Sliced Design (FSD)** principles, ensuring high cohesion,
loose coupling, and maintainable scalability.

```
Elite Regewelt/
├── public/                 # Static assets (favicons, SVG logos, og-images, llms.txt, robots.txt)
├── scripts/                # Build and maintenance scripts (image processing, icon generation)
├── e2e/                    # Playwright end-to-end test suites
└── src/
    ├── assets/             # Bundled vectors and images optimized by Astro Assets
    ├── data/               # Source JSON datasets (Vocabulary, Grammar, Exam, Quiz, Themen)
    │   ├── grammar/        # Systematic grammar data (verben, nomen, satz, etc.)
    │   ├── pruefung/       # B1/B2 exam schemas, modules, and redemittel
    │   ├── quiz/           # Goethe/TELC interactive quiz question banks
    │   ├── themen/         # 64 speaking/writing presentation arguments
    │   └── vocabulary/     # 12 thematic vocabulary JSON databases
    ├── features/           # Feature slices with internal models, UI, and APIs
    │   ├── auth/           # Login & registration presentation and validation
    │   ├── grammar/        # Grammar rule blocks, conjugations, and tables
    │   ├── pruefung/       # Module study views, timing cards, and model tests
    │   ├── quiz/           # Vue quiz island, question renderers, and result view
    │   ├── themen/         # Presentation topic cards and interactive argument explorer
    │   └── vocabulary/     # Topic stories, audio triggers, and vocabulary tables
    ├── widgets/            # Complex autonomous page widgets
    │   ├── hero/           # Dynamic hero component, statistics, badges & skeletons
    │   ├── navigation/     # Header navigation bar, mobile drawer, and menu toggles
    │   └── footer/         # Responsive footer with sitemap links and legal notices
    ├── layouts/            # Page layouts, HTML doctype, meta tags, and schema.org markup
    ├── pages/              # Astro file-based routing and SSR API endpoints
    │   ├── api/            # Serverless endpoints (TTS microservice with circuit breaker)
    │   ├── grammatik/      # Dynamic grammar routes [section]/[topicId].astro
    │   ├── vokabeln/       # Dynamic vocabulary routes [slug]/[topicId].astro
    │   ├── pruefung/       # Exam hub and level-specific modules [level]/index.astro
    │   ├── themen/         # Topic exploration and speaking guides [slug].astro
    │   ├── quiz/           # Interactive quiz islands [slug].astro
    │   └── index.astro     # Landing page with core hub highlights and platform statistics
    ├── shared/             # Reusable primitives, design system components, and utilities
    │   ├── ui/             # Buttons, Cards, Modals, PageHeaders, Skeletons
    │   ├── lib/            # Shared formatting, audio helpers, and dom utilities
    │   ├── model/          # Common types, schemas, and color tokens
    │   └── scripts/        # Clientside scripts and telemetry handlers
    └── styles/             # Global Tailwind v4 styles, theme variables, and keyframe animations
```

### Rendering & Island Strategy

```
┌────────────────────────────────────────────────────────┐
│                   Astro Page (SSG)                     │
│    Zero-JS Pure HTML/CSS Shell (Pre-rendered)          │
│                                                        │
│  ┌───────────────────────┐  ┌───────────────────────┐  │
│  │     Hero Widget       │  │  Grammar Rule Table   │  │
│  │   (Static Markup)     │  │   (Static Markup)     │  │
│  └───────────────────────┘  └───────────────────────┘  │
│                                                        │
│  ┌──────────────────────────────────────────────────┐  │
│  │         Vue 3 Interactive Island                 │  │
│  │   <QuizView client:visible />                    │  │
│  │   (Hydrated only when scrolled into view)        │  │
│  └──────────────────────────────────────────────────┘  │
│                                                        │
│  ┌──────────────────────────────────────────────────┐  │
│  │       Edge API Route: /api/tts (SSR on Vercel)   │  │
│  │   Dynamic audio generation + in-memory cache     │  │
│  └──────────────────────────────────────────────────┘  │
└────────────────────────────────────────────────────────┘
```

- **Static by Default (`output: "static"`):** All content, grammar rules, vocabulary hubs, and exam
  guides are pre-rendered into blazing fast static HTML.
- **Selective Hydration:** Vue components only load JavaScript when necessary (`client:visible` or
  `client:idle`), ensuring optimal Core Web Vitals (LCP < 0.8s, INP < 50ms, CLS = 0).
- **On-Demand Edge Route:** `/api/tts` explicitly opts into server rendering
  (`export const prerender = false`) to stream real-time neural audio on Vercel.

### Content Collection Pipelines

Configured via Astro's Content Layer API in `src/content.config.ts`:

- Strict validation via TypeScript & Zod schemas (`grammarCollectionSchema`,
  `vocabularyCollectionSchema`, `examCollectionSchema`, `themenCollectionSchema`,
  `quizCollectionSchema`).
- Built-in type safety with auto-generated TypeScript definitions (`astro sync`).

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/Omar-Akhji/Astro-deutsch.git
cd "Elite Regewelt"
```

### 2. Install Dependencies

Install all dependencies cleanly using Bun:

```bash
bun install --frozen-lockfile
```

### 3. Configure Environment Variables

Copy the example environment template:

```bash
cp .env.example .env
```

Open `.env` and set optional analytics or integration variables:

```ini
# Optional: Google Analytics 4 Measurement ID (e.g. G-ABC123XYZ)
PUBLIC_GA_MEASUREMENT_ID=

# Optional: Path to Google Service Account Credentials for Search Console MCP
# GOOGLE_APPLICATION_CREDENTIALS="C:/path/to/credentials.json"
```

### 4. Start the Development Server

Launch the local development environment:

```bash
bun run dev
```

The application will start at: 👉 **`http://localhost:4321`**

## 🚢 Deployment

The project is pre-configured for seamless continuous deployment on **Vercel**.

### Deployment Setup

1. Connect the repository to Vercel.
2. Ensure the framework preset is set to **Astro**.
3. Vercel automatically detects the root configuration:
   - **Install Command:** `bun install --frozen-lockfile`
   - **Build Command:** `bun run build`
   - **Output Directory:** `.vercel/output/` (configured via `@astrojs/vercel`)

## 🤝 Contributing & Code Conventions

1. **Strict Bun Usage:** Always use `bun` commands. Never commit `package-lock.json` or
   `pnpm-lock.yaml`.
2. **Path Aliasing:** Use `@/` for imports relative to `src/` (e.g.
   `@/shared/ui/button/Button.astro`).
3. **No `!important`:** Do not use `!important` in CSS or Tailwind classes. Solve conflicts using
   specificity or `@layer`.
4. **Accessible Semantics:** Use semantic HTML5 elements (`<main>`, `<nav>`, `<article>`,
   `<section>`, `<figure>`).
5. **Verify Pre-Commit:** Always run `bun run check && bun run lint` before committing changes.
